# Roadmap

moshVR is in pre-release development. This is a direction for the project,
not a release calendar or a promise of support for every declared headset.

## First public build

- Validate 2D and immersive use on physical Quest hardware: connection setup,
  keyboard and controller input, hands, audio consent, pause/resume and reconnect.
- Establish durable release signing and an update path.
- Resolve bundled SDK licensing and native dependency source provenance.
- Capture real screenshots and a short headset demo with non-sensitive data.
- Finish public support/privacy contact setup and confirm the distribution channel.

## Next improvements

- Improve the reconnect and session-restoration experience.
- Make host organization and long-session navigation more comfortable.
- Refine spatial input, placement and readability from real device feedback.

## Exploring

- tmux control mode for structured remote panes.
- Per-host color accents.
- Additional speech options that preserve explicit consent and review.

Requests are welcome through [contributions](../CONTRIBUTING.md). Small,
well-observed improvements are more useful than promises of broad rewrites.
