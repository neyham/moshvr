# moshVR identity

The wordmark leads; the terminal chevron and cursor come from the Android
app icon. Nested planes express the spatial workspace without pretending
to show a running app. The palette uses near-black, warm white and pale green.

| File | Use |
| :--- | :--- |
| `hero.svg` | Editable, self-contained README banner; 1280×480 |
| `social-preview.png` | GitHub repository social preview; 1280×640, solid background, under 1 MB |

Artwork contains no external fonts, scripts, image loads or tracking. It is
branding illustration, not a product screenshot. GitHub's social preview
must be uploaded in repository Settings; checking the file into Git alone
does not configure it.

Real headset media is still needed to demonstrate the experience. The
[media guide](../MEDIA.md) defines the capture sequence and privacy checks.
