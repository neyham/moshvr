# Real Quest capture

Captured on Quest 3, Android 14, on 2026-09-13 using the installed 0.1.0
development build. This is the empty immersive workspace in Construct mode,
with digital rain and tracked hand/controller pointers. It does not show
an SSH connection, mosh recovery or a completed release validation.

The source capture was stereoscopic. The exports use a fixed right-eye
crop, normal playback speed, and no audio. No synthetic interface, terminal
output or simulated input was added. Identifying source metadata was removed.

- `moshvr-quest3-interface-preview.mp4`: 9 seconds, H.264, 1080×1080, 30 fps.
- `moshvr-quest3-interface.gif`: 6 seconds, 640×640, 12 fps.
- `moshvr-quest3-interface.png`: a representative frame from the same clip.

The capture predates the spatial-dialog compatibility patch. A later part
of that device session exposed a dialog-window crash; it is excluded from
this short interface clip. The clip is not evidence that the fix passed
hardware retesting. Raw recordings and diagnostic material remain private.
